Доступ

Управление работает напрямую с GitHub: ни сервера, ни пароля на сайте нет. Нужен один токен — он хранится только в этом браузере.

1. Откройте создание токена.

2. Token name — beeble-art. Expiration — на ваш выбор, лучше 1 год.

3. Repository access → Only select repositories → beeblebroxxxy.github.io.

4. Permissions → Repository permissions → Contents: Read and write. Больше ничего не нужно.

5. Generate token, скопируйте его и вставьте ниже.
